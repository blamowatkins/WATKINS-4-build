# Watkins Bros Detailing

A responsive website for a mobile auto detailing service, built for the GIT 215 Module 4 coursework. Visitors can compare interior, exterior, and full-detail packages, see an example of the work, and prepare a booking request.

**[View the live site](https://blamowatkins.github.io/WATKINS-4-build/)**

## What I built

- Package cards with prices for cars and larger vehicles. Selecting a package fills in the service on the booking form.
- A before-and-after gallery for an interior detail.
- A booking form with a live price estimate based on the selected service and vehicle. Submitting prepares a text message in the visitor’s messaging app and displays a copyable version on the page.

## Built with

- [Semantic HTML](index.html) for the service sections, gallery, and form.
- [CSS Grid and Flexbox](style.css) for responsive layouts.
- [Vanilla JavaScript](booking.js) for package selection, price updates, and booking text.
- GitHub Pages for hosting.

## Preview locally

Clone or download the repository, then open `index.html` in a browser. The page runs without a build step. Opening the booking draft in a messaging app requires a device or browser configured to handle SMS links.
